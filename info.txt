PROJECT OVERVIEW
================================================================================

OBJECTIVE:
Develop a fully functional typing game in x86 Assembly Language (8088/8086)
where players type letters on rising balloons to pop them and earn points
within a 2-minute time limit.

TARGET PLATFORM:
- Processor: Intel 8088/8086 (16-bit real mode)
- Operating System: DOS or DOSBox emulator
- Display: VGA Mode 13h (320x200 pixels, 256 colors)
- Input: Keyboard via BIOS interrupts
- Sound: PC Speaker (optional)

GAME RULES:
1. Player has 2 minutes (120 seconds) to play
2. Balloons with random letters (A-Z) spawn at bottom and float upward
3. Type the letter on a balloon to pop it
4. Each popped balloon awards 10 points
5. Balloons that reach the top disappear (optional penalty)
6. Game ends when timer reaches zero
7. Final score displayed on game over screen

KEY FEATURES:
- Main menu with navigation (Play, Help, Exit)
- Real-time balloon spawning and movement
- Keyboard-driven gameplay
- Score tracking and timer display
- Pause functionality during gameplay
- Game over screen with statistics
- Custom VGA palette and background image
- Sound effects for balloon pops (bonus)

================================================================================
TECHNICAL SPECIFICATIONS
================================================================================

ASSEMBLY LANGUAGE:
- Syntax: NASM (Netwide Assembler)
- Architecture: x86 16-bit (8088/8086 compatible)
- Memory Model: COM executable (ORG 0x100)

GRAPHICS:
- Mode: VGA Mode 13h (320x200x256)
- Color Depth: 8-bit indexed color (256 colors)
- Palette: Custom 768-byte palette (palette.bin)
- Background: Raw image file (imgData.raw, 64000 bytes)

INTERRUPTS USED:
- INT 10h: Video services (mode setting, text display)
- INT 16h: Keyboard services (key detection, reading)
- INT 1Ah: Time-of-day services (timer, random seed)
- INT 21h: DOS services (file I/O, program termination)

================================================================================
CORE GAME MECHANICS
================================================================================

BALLOON SPAWNING:
- Random x-position (20-300 pixels)
- Start at y=199 (bottom of screen)
- Random letter assignment (A-Z)
- Spawn rate: Every 1-2 seconds (adjustable)
- Maximum simultaneous balloons: 10

BALLOON MOVEMENT:
- Upward motion: y -= speed (speed = 1-3 pixels/frame)
- Smooth animation using frame timing
- Removal when y < 0 (reaches top)

INPUT HANDLING:
- Non-blocking keyboard check (INT 16h, AH=01h)
- Letter keys (A-Z): Check for matching balloon
- ESC key: Pause game
- Ignore non-letter keys during gameplay

COLLISION DETECTION:
- Simple letter matching (no spatial collision)
- If typed letter == balloon.letter:
  - Remove balloon
  - Play pop sound
  - Increment score by 10
  - Update score display

TIMER SYSTEM:
- Total time: 120 seconds (2 minutes)
- Update every second using system clock (INT 1Ah)
- Display format: MM:SS (e.g., "02:00", "01:23")
- Game ends when timer reaches 00:00

SCORE SYSTEM:
- Initial score: 0
- Points per balloon: 10
- Score display: "SCORE: XXXX"
- No maximum score limit

================================================================================
DATA STRUCTURES
================================================================================

BALLOON STRUCTURE (10 bytes per balloon):
   Offset | Size | Description
   -------+------+---------------------------
   +0     | 2    | x_position (word)
   +2     | 2    | y_position (word)
   +4     | 1    | letter (byte, ASCII 'A'-'Z')
   +5     | 1    | color (byte, palette index)
   +6     | 1    | active_flag (byte, 0 or 1)
   +7     | 1    | speed (byte, pixels/frame)
   +8-9   | 2    | Reserved/padding

BALLOON ARRAY:
   balloon_array: times (10 * 10) db 0   ; 10 balloons x 10 bytes

GAME STATE VARIABLES:
   game_state        db 0      ; Current screen state
   current_score     dw 0      ; Player's score
   timer_seconds     db 120    ; Remaining time (seconds)
   current_selection db 0      ; Menu selection index
   balloon_count     db 0      ; Active balloon count
   game_paused       db 0      ; Pause flag

================================================================================
RANDOM NUMBER GENERATION
================================================================================

ALGORITHM: Linear Congruential Generator (LCG)
   Formula: next = (a * seed + c) mod m
   Parameters:
      a = 1103515245
      c = 12345
      m = 2^31

SEED SOURCE:
   - INT 1Ah: Read system clock ticks
   - Updated on each random call

USAGE:
1. Random X Position (20-300):
   random_value mod 280 + 20

2. Random Letter (A-Z):
   random_value mod 26 + 65 ('A' ASCII)

3. Random Color (for variety):
   random_value mod 16 + 240 (bright colors)

================================================================================
PERFORMANCE OPTIMIZATION
================================================================================

1. DIRECT VGA MEMORY ACCESS
   - Segment 0xA000 for fast pixel writes
   - Avoid BIOS calls in inner loops

2. SELECTIVE REDRAWING
   - Only redraw changed balloons
   - Use background buffer for clean erases

3. EFFICIENT LOOPS
   - Minimize register moves
   - Use REP STOSB for block fills

4. FRAME TIMING
   - Target 30-60 FPS
   - Use system clock for consistent speed

5. REDUCED FUNCTION CALLS
   - Inline critical sections where needed
   - Pre-calculate positions when possible
